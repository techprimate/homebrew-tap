# Homebrew Tap of techprimate

## How do I install these formulae?

`brew install techprimate/tap/<formula>`

Or `brew tap techprimate/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "techprimate/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
